# Output Contract

## Required Shape

Test Pattern, Behaviors Covered, Tests Added, Commands Run, Failures, Flake Risk, Coverage Gap, Remaining Manual Checks.

## Always Include

- Summary
- Evidence Reviewed
- Risk Level
- Confidence
- Recommendation or Change
- Verification
- Open Questions or Blockers

## Quality Bar

- Specific file paths or runtime signals beat generic advice.
- Explain why a risk matters, not just that it exists.
- Make the next step executable.
